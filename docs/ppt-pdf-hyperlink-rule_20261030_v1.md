# PPT → PDF 하이퍼링크 규칙 (2026-10-30)

- 증상: 주간브리프 편집용 PPTX를 PowerPoint에서 "PDF로 저장"하면 기사 요약 카드의 "원문 기사 확인" 링크(섹션당 2개, 14개)가 PDF에서 사라짐.
- 원인: PowerPoint PDF 내보내기는 **도형(shape) 클릭 링크만** PDF 링크로 남기고, 텍스트 런(run) 하이퍼링크는 버림(빈 덱 실험으로 확인: run 링크 0개, shape 링크 1개).
- 규칙: PPTX의 모든 외부 링크·쪽 이동은 도형 클릭 링크로도 걸어야 한다. run 링크는 덱 안 클릭용으로 함께 둬도 된다.
- 반영: `scripts/w2_native_pptx_v1.py` `_card()`가 카드 도형에 원문 URL을 shape 링크로 추가.
- 검증: 10/19~10/25 주간본 재빌드(v6) → PowerPoint SaveAs PDF에서 외부 링크 50/50, 목차 이동 유지(이전 36/50).
